# UI Components

- Use shadcn/ui components exclusively for all UI elements (installed in `resources/js/Components/ui`)
- Do not create custom React primitives when a shadcn/ui equivalent exists
- If a needed component is not installed, install it from the shadcn/ui registry before use
- Follow shadcn/ui conventions for styling and composition

> Detail, migration mappings, and Luminous-token notes: see `.ai/rules/components.md`.
